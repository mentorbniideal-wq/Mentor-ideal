# Monthly History backfill

The Monthly Report Center has two separate workflows. The existing Monthly Sync remains the operational current-period import. The History tab shows ten reporting periods at a time and accepts the three BNI CSV reports for one past period. It previews identity matching and period checks before an explicit confirmation. It never calls the operational Monthly Sync action.

Historical backfill writes only `member_performance_source_snapshots` and its existing `monthly_sync_batches` ledger and audit event. It does not write current member details, current score, renewals, or operational counters. Re-importing a period updates its source snapshots by `(chapter_id, member_id, period_year, period_month, source_type)`, while retaining the old batch metadata and pre-import rows in `before_snapshot`. Growth trusts only a completed batch with all three file hashes. An incomplete or failed import is not trusted.

Both actions require an authenticated OAuth account with the existing Monthly Sync execute capability; chapter scope comes from the server. The preview expires after 30 minutes. Unknown or ambiguous member names, duplicate rows, missing files, and an Evolution report containing a period later than the chosen month fail closed. A Member Traffic Light period is checked when the source states one. If it does not state one, the preview explicitly requires the operator to verify the source manually. Reporting2You source-window semantics remain unverified: values are raw report snapshots, never labeled monthly activity.

This workflow uses existing tables and needs no migration. It is intentionally not a database transaction across the batch ledger, audit event, and snapshot upsert. A failure marks the batch failed and the period untrusted; review the batch before retrying. No automatic rollback or deletion of historical records is provided. The new grid uses existing theme tokens and responsive rules; keyboard focus, loading, empty, error, preview, confirmation, and success states are included.
